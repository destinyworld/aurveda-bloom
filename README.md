# Ayur Wellness Guide

# Build a Modern Ayurvedic & Natural Healing Tips App

Create a beautiful, modern, mobile-first wellness web app that provides concise educational information about **Ayurveda, natural remedies, herbal approaches, yoga, meditation, nutrition, lifestyle practices, and other complementary wellness therapies** for common health conditions.

The app should feel premium, calming, trustworthy, and easy to explore — combining the visual style of a modern health app with traditional Ayurvedic aesthetics.

## 1. App Concept

The app is an **Ayurvedic & Natural Wellness Guide**.

Users land on a beautiful home screen containing a searchable, categorized list of common diseases and health conditions. When a user selects a condition, open a dedicated health-information page containing concise, easy-to-understand wellness suggestions.

The content should be presented as **complementary wellness information, not as a replacement for professional medical diagnosis or treatment**.

Avoid claiming that herbs or alternative therapies can cure diseases.

# 16. Important Medical Content Rules

This is an educational wellness application.

Do NOT claim:

- "This herb cures cancer."
- "Ayurveda can cure diabetes."
- "This remedy replaces medicine."
- "Doctors are unnecessary."
- "This treatment is guaranteed."

Instead use responsible language such as:

- "May support..."
- "Traditionally used for..."
- "Some people use..."
- "Evidence is limited..."
- "Talk with a qualified healthcare professional before using..."
- "Do not stop prescribed medication without medical advice."

For herbs, supplements and traditional preparations, include appropriate cautions about medication interactions, pregnancy, breastfeeding, allergies, kidney/liver conditions and other relevant risks.

## Development

```sh
git clone <this-repository-url>

```

## AI Plans

Copy `.env.example` to `.env.local` and set `AI_GATEWAY_API_KEY`. The key must never use a `VITE_` prefix or be sent to the browser. `AI_GATEWAY_MODEL` is optional and defaults to `openai/gpt-4o-mini`. Plan details are sent to AI Gateway for generation and are not stored by this app. Run with `npm run dev` locally or `npm start` after building.

## Android

Install Android Studio and its Android SDK, then add the Android project once with `npm run cap:add`. This app uses server-side rendering, so the native WebView loads a running or deployed app URL instead of bundling the SSR output as static files.

For an Android emulator, add `CAPACITOR_SERVER_URL=http://10.0.2.2:3000` to `.env.local`, start the dev server with `npm run dev:android`, then run `npm run cap:sync` and `npm run cap:open`. For release builds, set `CAPACITOR_SERVER_URL` to the deployed HTTPS origin in `.env.local` before syncing.
